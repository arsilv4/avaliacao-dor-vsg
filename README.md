# Avaliação da Dor: o 5º Sinal Vital (Simulação Clínica Virtual)

Versão jogável (WebGL) de uma simulação clínica virtual para estudantes de Enfermagem: avaliação da dor em uma enfermaria de clínica cirúrgica (Escala Verbal Numérica e PAINAD).
Jogue pelo link do GitHub Pages deste repositório. Funciona melhor em Chrome, Edge, Firefox ou Safari atualizados, em computador.

Créditos: avatares e animações Microsoft Rocketbox (licença MIT); fonte Inter (SIL Open Font License); texturas ambientCG (CC0);
vozes sintéticas geradas localmente com Chatterbox Multilingual (MIT). Casos clínicos fictícios.
